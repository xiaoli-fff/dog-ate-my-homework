A dog's excuse for eating the homework: it only ate the pages with the wrong answers, so technically it did the homework and then quality-checked it.

## Run it

```sh
node main.ts
```

The program writes the one line to the directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`) as `entry.txt`.
